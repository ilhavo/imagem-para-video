
# 🎬 Imagem para Vídeo Cinematográfico com Estilo

Este projeto permite gerar vídeos cinematográficos a partir de imagens usando [Stable Video Diffusion](https://stability.ai/news/stable-video-diffusion) e uma interface interativa Gradio, tudo diretamente no Google Colab.

---

## ▶️ Abrir diretamente no Google Colab

[![Abrir no Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/ilhavo/imagem-para-video/blob/main/imagem_para_video_filme.ipynb)

---

## 📦 Funcionalidades

- Upload de imagens individuais
- Escolha de estilo visual (cinematográfico, anime, pintura, etc)
- Movimento de câmara (zoom, pan)
- Configuração de FPS e duração
- Adição de legendas e efeitos
- Geração do vídeo final com download

---

## 🚀 Como usar

1. Torna este repositório **público temporariamente** (ver instruções abaixo).
2. Clica no botão **"Abrir no Colab"** acima.
3. Sobe as tuas imagens e configura os parâmetros na interface.
4. Gera e faz download do vídeo final.
5. (Opcional) Volta a tornar o repositório **privado**.

---

## 🔐 Como alternar entre Público e Privado no GitHub

### ➤ Tornar **Público**:

1. Vai à aba **Settings** do repositório no GitHub
2. Rola até à secção **Danger Zone**
3. Clica em **“Change repository visibility”**
4. Seleciona **Public** e confirma

### ➤ Voltar a **Privado**:

1. Vai novamente à aba **Settings**
2. Rola até **Danger Zone**
3. Clica em **“Change repository visibility”**
4. Seleciona **Private** e confirma

> ⚠️ Só podes mudar a visibilidade se fores o dono ou tiveres permissões de admin no repositório.
